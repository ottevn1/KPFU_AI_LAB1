# Лабораторная работа №1. Введение в машинное обучение и подготовка данных

## 1. Выбранный датасет

**Bank Marketing Dataset** (`bank.csv`)  — данные телефонной маркетинговой кампании банковского учреждения. Каждая строка — один клиент, с которым связался колл-центр, предлагая открыть срочный депозит.

Источник: [Bank Marketing Dataset на Kaggle](https://www.kaggle.com/datasets/janiobachmann/bank-marketing-dataset)

## 2. Бизнес-задача

Разработать модель бинарной классификации для прогнозирования вероятности оформления клиентом срочного депозита (`deposit`: yes/no). Прогноз строится на основе демографических характеристик (возраст, уровень образования, 
семейное положение), текущего финансового состояния (баланс счёта, наличие кредитов) и истории предыдущих взаимодействий с банком. 

Внедрение такого алгоритма позволяет финансовому учреждению перейти от стратегии массового обзвона к скоринговой приоритезации клиентской базы. Операторы колл-центра смогут фокусировать усилия на сегментах с максимальной 
расчётной вероятностью положительного отклика, что существенно повышает конверсию маркетинговых активностей и снижает операционные издержки на нецелевые звонки без увеличения общего бюджета.

## 3. Краткое описание пайплайна

1. Загрузка данных, первичный осмотр (`shape`, `info`).

2. Из набора признаков исключены `duration` (длительность звонка, чтобы избежать утечки данных, так как она неизвестна до звонка), а также `day` и `month` как слабоинформативные без привязки к году.

3. EDA: расчёт среднего возраста и баланса в разрезе уровня образования (`groupby` по `education`); построение диаграммы размаха (`boxplot`) для оценки распределения возраста в зависимости от решения клиента.

4. Предобработка: One-Hot Encoding категориальных признаков (`pd.get_dummies` с параметром `drop_first=True`), стратифицированное разбиение на train/test (80/20, `stratify=y`), масштабирование числовых признаков (`age`, `balance`, `campaign`, `pdays`, `previous`) через `StandardScaler` (параметры `fit` вычислены строго на train для предотвращения утечки данных).

5. Моделирование: обучение `RandomForestClassifier` с параметром `class_weight="balanced"` для компенсации дисбаланса классов, итоговая оценка качества через `accuracy_score`.

## 4. Основные выводы

1. Возраст является значимым предиктором. Визуальный анализ (boxplot) показывает, что медиана возраста клиентов, открывших депозит, составляет около 41 года, тогда как в группе отказавшихся она ниже — около 39 лет. Клиенты старшего возраста статистически чаще соглашаются на предложение.

2. Уровень образования коррелирует с финансовым состоянием. Клиенты с высшим образованием (tertiary) имеют наибольший средний баланс на счёте (в среднем более 1800 у.е.), что делает их приоритетным сегментом для продвижения депозитных продуктов.

3. Балансировка классов критически важна. Исходные данные имеют сильный дисбаланс: около 89% отказов (no) против 11% согласий (yes). Применение class_weight="balanced" не позволило модели скатиться в тривиальный прогноз "no" для всех и существенно повысило полноту (Recall) по целевому классу.

4. Модель готова к практическому применению. Алгоритм, обученный только на признаках, доступных до звонка (без duration, day, month), демонстрирует общую точность (accuracy) на уровне 89–91% на тестовой выборке. Это заметно лучше случайного угадывания и полностью пригодно для приоритезации базы клиентов перед обзвоном.
