## 3. Выбор датасета

Для выполнения работы вам необходимо выбрать один из предложенных экономических датасетов на Kaggle (или согласовать аналогичный набор бизнес-данных для задачи бинарной классификации):

* **Bank Marketing Dataset**: Прогнозирование того, откроет ли клиент срочный депозит в банке на основе данных маркетинговой кампании.
* **IBM HR Analytics Employee Attrition**: Предсказание увольнения сотрудников и выявление факторов, влияющих на текучесть кадров.
* **Credit Risk Dataset**: Оценка кредитного риска (выдача кредита: хороший/плохой) на основе финансовых и демографических показателей заемщика.

## 4. Задачи для самостоятельной реализации

Вам предстоит самостоятельно пройти путь, разобранный на практике, используя те же самые инструменты, но на новых данных. В вашем Notebook должны быть реализованы следующие этапы:

1. **Настройка окружения**: Импорт изученных библиотек (`numpy`, `pandas`, `matplotlib.pyplot`, `seaborn`, `sklearn`).
2. **Загрузка и первичный анализ данных**:
    * Чтение датасета через Pandas.
    * Вывод базовой информации о размерности (`shape`) и первых строк (`head`).
    * Обоснованное удаление столбцов (`drop`), не несущих экономической пользы для прогноза (например, ID транзакций, имена клиентов и т.д.).
3. **Разведочный анализ (EDA)**:
    * Группировка данных (`groupby`) для сравнения экономических показателей в разрезе выбранной категории (например, средний баланс по полу).
    * Построение визуализации с помощью «Ящика с усами» (`sns.boxplot`) для выявления зависимости целевой переменной от одного из числовых признаков.
    * **Обязательно напишите краткий аналитический вывод по графику.**
4. **Feature Engineering и Предобработка**:
    * Преобразование текстовых номинальных признаков в бинарные колонки с помощью алгоритма One-Hot Encoding (`pd.get_dummies` с параметром `drop_first=True`).
    * Разделение данных на матрицу признаков (`X`) и целевую переменную (`y`).
    * Разбиение данных на обучающую и тестовую выборки (`train_test_split` с параметром `stratify`).
    * Масштабирование числовых признаков с помощью `StandardScaler`. Помните о предотвращении утечки данных (обучение скалера только на Train-выборке).
5. **Обучение и оценка модели**:
    * Инициализация и обучение алгоритма `RandomForestClassifier`.
    * Получение прогноза на тестовой выборке (`predict`).
    * Оценка качества модели метрикой `accuracy_score`.
    * **Финальный бизнес-вывод**: Как полученный результат и метрика помогут бизнесу принимать более эффективные решения?
